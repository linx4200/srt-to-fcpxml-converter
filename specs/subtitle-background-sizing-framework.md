# Subtitle Background Sizing Framework

## 1. 目标

字幕背景根据每个 `Subtitle Clip` 的实际文字尺寸自动生成安全包围盒，使单行和多行字幕都能被完整覆盖。用户可以在自动尺寸之上调整额外留白，但背景尺寸不得小于文字的安全包围盒。

浏览器 preview rendering 与 FCPXML 导出必须共享同一套背景尺寸计算规则，避免预览与 Final Cut Pro 导入结果使用不同的尺寸模型。

## 2. 已确认的设计结论

### 2.1 按每条字幕自动计算背景尺寸

每个 `Subtitle Clip` 独立计算背景尺寸。计算输入至少包括：

- 当前字号。
- 当前 Target Video Orientation 对应的参考分辨率。
- 当前 `Subtitle Clip` 的 Logical Preview Lines。
- 各行文字的测量宽度。
- 用户设置的横向与纵向额外留白。

背景的最小宽度由最宽一行文字决定，背景的最小高度由字号、行高和实际行数决定。单行、双行和多行字幕允许生成不同尺寸的背景框。

### 2.2 背景尺寸不能小于文字安全包围盒

文字安全包围盒是背景尺寸的硬下限。用户调整背景时只能增加或减少额外留白，不能让最终背景宽度或高度小于文字安全包围盒。

设置界面应直接表达可生效的参数，例如“横向留白”和“纵向留白”。不要继续让用户编辑一个可能被内部下限截断、但界面仍显示为更小数值的背景绝对宽高。

### 2.3 字号单向影响背景

字号变化后，系统重新计算当前字幕的文字安全包围盒和最终背景尺寸。背景留白参数保持不变。

用户调整背景留白时，只改变背景尺寸，不修改字号，也不触发 `Subtitle Reflow`。

### 2.4 统一尺寸计算边界

文字测量、行数统计和背景尺寸计算属于纯结构性算法，应放在 `utils` 或现有字幕布局领域边界中。UI 组件只负责读取计算结果并渲染，FCPXML 生成逻辑消费同一计算结果，不在 `PreviewSubtitle` 与 `fcpxml.ts` 中分别维护公式。

### 2.5 使用横向与纵向总留白

设置界面使用“横向总留白”和“纵向总留白”，数值表示背景在对应方向上比文字安全包围盒增加的总尺寸。总留白由文字两侧平均分配。

横向和纵向的默认总留白均为 5px，使背景在四个方向上尽量贴近文字。留白单位使用 Target Video Orientation 的 FCP 参考像素，并按现有预览比例缩放。

### 2.6 竖屏与横屏使用同一套自适应规则

背景框不能按 Target Video Orientation 使用固定宽度。竖屏与横屏都必须根据当前 `Subtitle Clip` 的最宽 Logical Preview Line 计算背景宽度，避免横屏单行字幕超出固定背景框。

Subtitle Reflow 先根据当前 Target Video Orientation 的字幕安全区域生成 Logical Preview Lines，背景再包围最终行宽。字幕安全区域只约束文字换行，不截断用户设置的背景留白；背景可以在用户主动增加留白时越过安全线。

### 2.7 使用稳定的文字尺寸公式

文字安全高度使用项目现有的字号换算与行高规则计算，不读取浏览器 DOM 的实际高度。背景高度按单行高度乘以 Logical Preview Line 数量，再增加纵向总留白。

文字安全宽度继续使用项目现有的字幕文字测量能力，背景宽度取最宽 Logical Preview Line 的测量宽度，再增加横向总留白。浏览器预览和 FCPXML 导出必须调用同一个纯计算函数。

稳定公式用于保持不同浏览器环境下的可重复性，并避免把浏览器字体度量误当成 Final Cut Pro Custom title 的权威尺寸。

### 2.8 使用留白字段替代绝对背景宽高

`subtitleStyle` 不再保存全局固定的 `backgroundWidth` 和 `backgroundHeight`，改为保存横向与纵向总留白。默认值均为 5px。

重置字幕样式时恢复默认留白。设置界面直接编辑留白字段，最终背景宽高始终由当前 `Subtitle Clip` 的文字安全包围盒和留白共同派生，不作为另一份可变状态保存。

## 3. 推荐计算流程

1. 从 Working Timeline 读取当前 `Subtitle Clip` 文本。
2. 使用当前字幕布局规则生成 Logical Preview Lines。
3. 测量每行文字宽度，并取最大值作为文字安全宽度。
4. 根据字号、行高和实际行数计算文字安全高度。
5. 在安全宽高上增加用户设置的横向与纵向留白。
6. Preview rendering 使用计算后的参考画幅像素尺寸绘制背景 sibling layer。
7. FCPXML 为对应 `Subtitle Clip` 使用相同尺寸生成矩形背景坐标。

空文本不生成字幕背景。关闭字幕背景时不执行背景尺寸渲染，也不在 FCPXML 中生成矩形背景层。

## 4. 实现约束

- 背景尺寸是派生结果，不写入 Working Timeline，也不维护独立的可变副本。
- 修改字号会改变文字包围盒和背景尺寸；修改背景留白不会改变字号。
- 横向总留白的每次调整都必须改变背景宽度，不得因字幕安全区域产生无响应区间。
- UI 不独立测量或编排背景尺寸。
- FCPXML 继续在每个 `Subtitle Clip` 内生成与字幕具有相同 offset 和 duration 的矩形背景层。
- FCPXML 开启背景时使用正 lane：矩形背景位于 `lane="1"`，字幕文字位于 `lane="2"`；关闭背景时字幕文字位于 `lane="1"`。
- 纯尺寸计算需要覆盖空文本、单行、多行、最大字号、竖屏和横屏输入。
